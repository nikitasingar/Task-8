# 📊 Task 8: Simple Sales Dashboard 

## 🎯 Objective
To design a basic and interactive sales dashboard using **Power BI**, showcasing performance by **Product Category**, **Region**, and **Monthly Trends**.

---

## 🛠 Tools Used
- **Power BI Desktop**
- **Dataset**: Superstore_Sales.csv (or similar dataset with columns like Order Date, Region, Category, Sales, Profit)

---

## 📌 Key Steps Followed

1. Imported and explored the dataset in Power BI.
2. Converted the **Order Date** column into **Month-Year** format using Power Query.
3. Created the following visuals:
   - 📈 **Line Chart** – Sales over Months
   - 📊 **Bar Chart** – Sales by Region
   - 🍩 **Donut Chart** – Sales by Category
4. Added **Slicer** for Region to filter all visuals interactively.
5. Applied consistent color themes and conditional formatting to highlight top-performing areas.
6. Designed a clean and intuitive layout using grid alignment and consistent fonts.

---

## 💡 Insights Derived

1. **West region** had the highest total sales during Q3.
2. **Technology** category contributed the highest profit margin.
3. Monthly sales showed a **peak in November**, indicating seasonal trends.
